ANÁLISE DE REQUISITOS
 
RF01 - Gestão de Grupos: O sistema deve permitir o cadastro dos grupos de A a L.
 
RF02 - Gestão de Seleções: O sistema deve permitir o cadastro das 48 seleções, incluindo o nome, bandeira, abreviação e grupo.
Regra: O grupo deve ser selecionado do cadastro de grupos existente.
 
RF03 - Gestão de Sedes: O sistema deve permitir o cadastro das sedes, incluindo o nome do país, a cidade, o estádio e a capacidade do estádio.
 
RF04 - Gestão de Partidas: O sistema deve permitir o cadastro das partidas, incluindo a data, horário, sede, seleção mandante e a seleção visitante.
Regras:
- A sede deve ser selecionada
- As seleções mandantes e visitantes devem ser selecionadas
 
Create	- Incluir
Read	- Consultar
Update	- Alterar
Delete	- Excluir / fake
 
RF05 - Tabela das partidas: O sistema deve permitir a criação da tabela com as partidas para visualização pelo usuário.
Regras: As partidas precisam ser organizadas em grupo e em data cronológica.
 
RF06 - Resultado das partidas: O sistema deve permitir a inclusão dos resultados das partidas com a opção de incluir a quantidade de gols que cada seleção marcou.
Regras: Os resultados devem ser igual ou maior que zero.
 
RF07 - Classificação: O sistema deve permitir a visualização do ranking de cada grupo, mostrando os melhores classificados em primeiro.
Regras: Os critérios para geração do ranking deve ser:
- pontuação
- número de vitórias
- saldo de gols
- verificar...
 
RF08 - Avanço de fase: O sistema deve calcular quais seleções irão avançar para a próxima fase.
Regras da primeira para a segunda fase: 
- Os 2 primeiros colocados avançam para a próxima fase, totalizando 24.
- Os 8 melhores colocados dentre restantes também avançam para a próxima fase, totalizando assim, 32 seleções
- Demais regras de avanço nas próximas fases: verificar...
