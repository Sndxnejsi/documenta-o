# Documentação técnica
## Requisitos técnicos
### aplicação desktop
-linguagem C#,C++,C / Visual Studio 2026
-Banco de dados     /PostgreSQL
-infraestrutura de hospedagem  /Windows 10 ou Superior
### aplição web
-linguagem
   -Front-end HTML ,CSS ,javascript,React
   -Back-end Node.js , javascript ,PHP (possivelmente)
-Banco de dados  MySQL / MariaDB
-infraestrutura de hospedagem  1vCPU , 2GB RAM ,50GB SSD
-domínio (registro.br)
-serviço de segurança Cloudflare ou similar

### aplicação mobile
-linguagem React Native com javascript
-Banco de dados  /API
-infraestrutura de hospedagem (ambiente que simula  as lojas do android e iphone)
